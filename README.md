# ModsHub - Platform Berbagi Mods

Website modern untuk memposting, mencari, dan berbagi aplikasi mods dengan desain yang simple, unik, keren, dan modern.

## 🌟 Fitur Utama

✨ **Desain Modern**
- Interface yang elegan dengan gradient warna yang menarik
- Animasi smooth dan responsif
- Dark theme yang nyaman di mata
- Support mobile-first design

🔍 **Pencarian & Filter**
- Search real-time untuk mencari mods
- Filter berdasarkan kategori (Game, Aplikasi, UI/Theme)
- Hasil pencarian instant tanpa refresh

📤 **Upload Mods**
- Modal form yang user-friendly
- Validasi form lengkap
- Preview mods sebelum diupload

🎨 **Kategori Mods**
- Game Mods
- Application Mods
- UI/Theme Customization

⭐ **Rating & Downloads**
- Tampilkan rating dari pengguna
- Tracking jumlah download
- Author information

## 🚀 Mulai Menggunakan

### Requirements
- Browser modern yang support ES6
- Koneksi internet (untuk Font Awesome icons)

### Instalasi

1. Clone repository
```bash
git clone https://github.com/saskamods/mods-posting-website.git
cd mods-posting-website
```

2. Buka file `index.html` di browser
```bash
# Gunakan live server (jika menggunakan VSCode)
# atau
open index.html
```

## 🔄 Cara Kerja

### Upload Mods
1. Klik tombol "Upload" atau "Upload Mods" di hero section
2. Isi form dengan detail mods Anda:
   - Nama Mods
   - Kategori
   - Deskripsi
   - Nama Pembuat
   - Link Download
   - URL Gambar Thumbnail
3. Klik "Upload Mods"
4. Mods akan langsung tampil di halaman

### Cari Mods
1. Gunakan search bar untuk mencari berdasarkan nama, deskripsi, atau author
2. Atau gunakan filter tag untuk kategori spesifik
3. Hasil akan update secara real-time

### Download Mods
1. Klik kartu mods yang Anda inginkan
2. Klik tombol "Download"
3. Proses download akan dimulai
